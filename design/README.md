# design/ — design-lab material

Interactive HTML studies and the deterministic flight-sim harness. Reference,
not part of the build.

Naming note: the live mascot was rebranded **parrot → słowik** (a nightingale,
the surname) on 2026-07-04 — see `slowik-rebrand.md` for the full decision
record. The studies here predate that and keep their historical `parrot-*`
names: they document decisions made under the old name, and
`parrot-flight-sim.js` is still the live, mandatory tuning harness for
`src/lib/slowikFlight.ts` / `src/lib/slowikCompanion.ts` (its filename and
battery names are load-bearing references in CLAUDE.md and project memory).
New sprite studies for the nightingale go in new `slowik-*` files.
